# Public geodata for Field Notes — what is usable, and how (2026-09-15)

Prompted by Austin's look at UT Austin's GIS Center and TxGIO. Question:
what can a new user anywhere in the USA get pre-loaded, and what can Texas
get on top. Research by web fetch on 2026-09-15; "unverified" means the
terms page could not be read and the verdict is inferred.

Verdicts: **bundle** = ship in the app; **per-property** = download once for
one place, no account; **online** = live layer or query, user-triggered;
**skip**.

## Texas (TxGIO, geographic.texas.gov, formerly TNRIS)

| Source | What | Terms | Verdict |
|---|---|---|---|
| DataHub API `https://api.tnris.org/api/v1/collections/` and `/resources/` | 237 collections, 345k files, direct S3 URLs, no login. Imagery (NAIP 60 cm 2018–2024, StratMap 6-in regional), lidar (50 cm–1 m DEM + contours + LAZ per quarter-quad, no hillshade product), hydrography, county parcel zips, NLCD, TPWD Natural Regions | CC0-1.0 on every collection (verified in JSON) | **per-property**: qquad imagery + DEM + contours ≈ 50–100 MB, county parcels 1–70 MB rural. Only the qquad/county name leaves the phone. |
| Texas Imagery Service (Hexagon 6-in statewide) | WMTS/WMS behind org-specific URLs | Government and their contractors only; paid; no redistribution or caching (verified on the request form; EULA PDF 403) | **skip** |
| StratMap parcels, 2025 collection | 253 county zips + statewide 2.77 GB, SHP/GDB, standard schema, "not survey grade" | CC0-1.0 | **per-property (county zip)** to pre-fill a boundary; the live FeatureServer would leak a point query |
| `imagery.geographic.texas.gov` / `feature.geographic.texas.gov` ArcGIS REST | NAIP, StratMap, parcels, hydrography as dynamic services | Data CC0; service ToS unverified; every request sends a bbox | **online preview only** |

## National baseline (any state)

| Need | Source | Verdict |
|---|---|---|
| Tracing imagery | USGS NAIPPlus ImageServer `exportImage` (0.3 m, public domain, no key, bbox goes to USGS) | **per-property** (already the capture-imagery source). Keep USGSImageryOnly as the online fallback. Esri World Imagery, Mapbox, MapTiler: keys and no-harvest terms, never as offline sources. |
| Elevation | USGS 3DEP: TNM Access API by bbox (1 m COG tiles ≈ 315 MB, range-readable), `3DEPElevation` ImageServer with hillshade/slope/contour raster functions | **per-property** exportImage; in Texas prefer TxGIO 50 cm DEM qquads (12 MB) |
| Parcels | No free national set. Free statewide verified: TX (CC0), FL, OH, NC (disclaimer only), MT (license unverified). OR is county-by-county. | **per-property, state-aware registry**; statewide multi-GB zips need desk-side clipping |
| State/county lines | Census cartographic boundaries (state 1:20m = 235 KB as GeoJSON, county 500k ≈ 12 MB) | **bundle** — states shipped 2026-09-15 as `assets/geo/us_states.geojson` |
| Ecoregions | EPA Level III CONUS 28 MB, Level IV per state (TX 4.2 MB); federal, public domain (unverified) | bundle L3 simplified later; per-state L4 on demand |
| Hardiness zones | PRISM/OSU 2023, free with USDA-ARS + OSU logos or a "not the official map" disclaimer | bundle the ZIP-code CSV if wanted |
| MLRA | NRCS 2022, 5 MB, public domain | bundle later |
| Species | USDA PLANTS: complete checklist CC0, but nativity is by jurisdiction (L48/AK/HI/PR), not state; state presence exists on the site, not in bulk. BONAP copyrighted. iNaturalist `species_counts?place_id=<state>&native=true` gives per-state native/introduced with counts (TX: 4,202 native, 1,394 introduced); commercial-use terms for bundling unverified. | **user-triggered fetch per state** (shipped, D-034); bundled per-state palettes only where curated (TX today) |
| Soil | NRCS Soil Data Access (national, no auth, point query = leak) ; county SSURGO zips from Web Soil Survey for offline | online on explicit action (already D-022); county zip per-property later |
| NRCS practice codes | No official CSV; the FY2023 Practice and Conservation Activity List PDF (111 pp) is parseable, ~170 codes | bundle a curated CSV later |

## Recommendation

1. Texas data pack = TxGIO DataHub per-property downloads (qquad imagery +
   DEM + contours, county parcels, county SSURGO) behind one "Get the map
   pack for this place" button that names only the quarter-quad and county.
   Not built yet; the API is stable and needs no key.
2. National baseline = what shipped today (state resolution, state-aware
   species, survey protocols) plus NAIPPlus and 3DEP per-property downloads
   which the map already has for imagery.
3. Never TIS, never Esri/Mapbox tiles offline.
